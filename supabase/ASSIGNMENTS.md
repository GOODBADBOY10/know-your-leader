## Updating this file

Whenever you assign someone to one of the remaining states, add their name
to the corresponding row above (or add a new row if the state isn't listed
yet). When someone finishes their state (flips `"_status"` to `"verified"`
in their JSON file and it's merged to `main`), update their status to ✅.

Keep one row per state — if someone is assigned multiple states, give them
a separate row for each rather than listing multiple states in one row.
This keeps the table easy to scan and avoids the mix-up that happened
before (several states were accidentally left off the "unassigned" list
because they were buried inside another person's row).
